启用代理
开启后抓取流量经代理出口，站点看到的是代理 IP 而非本机 IP
代理地址
支持 socks5h:// / socks4:// / http://；Tor 默认端口 9150。socks5h 由代理端解析 DNS，避免本地 DNS 泄露访问域名
出口 IP 轮换
由 Tor 的 NEWNYM 信号实现，不使用随机免费代理池 —— 那些代理的运营者能看到全部流量明文， 隐藏身份反而交给了陌生人；频繁换 IP 本身也会打出「同一客户端在轮换」的规律，更易被关联。 Tor 的换线路是协议自带的标准动作，中继为志愿者，来源可信。
自动换 IP
按下方阈值自动请求新出口；需 Tor 在运行，未运行时明确报错而不是假装成功
按时间轮换
距上次换 IP 超过该秒数则轮换（0 = 不按时间）
按次数轮换
累计抓取达到该次数则轮换（0 = 不按次数）
Tor 控制端口
需在 torrc 开启 ControlPort（常见 9051）并配置 CookieAuthenticationFile
