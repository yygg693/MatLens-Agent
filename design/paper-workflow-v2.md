# 论文工坊 v2 · 深度定制设计方案

> 基于 matlens（改造的 Hermes）深度定制，老项目（mra）仅作参考。
> 论文工坊是 MatLens 项目**主推功能**，按精品标准设计。

## 一、继承老项目的设计原则（搬精华，不搬代码）

| 老项目原则 | v2 落地 |
|---|---|
| 每阶段独立可重跑，输入输出落库 | `papers.stages_json` 存 7 步产物，失败单独重跑，断点续写 |
| 角色化多 Agent（每步独立 prompt） | `paper_engine/prompts.py` 7 份角色 prompt（选题/检索/大纲/写作/巡检/审稿/导出） |
| 写作只引用已核验文献（杜绝幻觉引用） | **引用白名单机制**：检索步产出 refs 列表，写作步只允许引用白名单内文献 |
| 检索 = LLM 查询改写 + 并发检索 | v2 升级为**双通道**（见下） |
| 导出 Markdown/LaTeX/Word | v2 一期 Markdown + LaTeX，二期 Word |

## 二、架构（matlens_kit/paper/）

```
matlens_kit/paper/
├─ engine.py     工作流引擎：STAGES 状态机 + 每步执行 + 断点续写
├─ db.py         papers.db（SQLite：papers 表 + 复用 SessionDB 连接模式）
├─ prompts.py    7 份角色 prompt（材料科研场景深度定制）
├─ quality.py    质量巡检：引用核验 / 结构检查 / AI 味启发式
├─ export.py     Markdown + LaTeX + GB/T 7714 引用渲染
└─ (api) papers_api.py  HTTP 层（同进程调 engine）
```

## 三、7 步深度定制设计

### 1. 选题（topic）
- 输入：研究方向/关键词 + 论文类型（综述/研究论文）
- Agent 产出：选题背景、研究问题、目标期刊定位、创新点初判
- **联动记忆**：读取 Mem0 用户研究方向记忆，自动填充偏好

### 2. 检索（search）——v2 核心升级：双通道
- **通道 A：RAG 本地知识库**（matlens 已有 rag_search）——用当前激活知识库，结果带 source/score
- **通道 B：OpenAlex 网络检索**（参考老项目 literature_survey，LLM 改写中英检索式 + 并发）
- 合并去重排序 → 产出**核验文献列表**（id/标题/作者/年份/摘要/来源）
- 落库为**引用白名单**（后续写作/写作引用只能从这里取）

### 3. 大纲（outline）
- 按论文类型生成结构：综述（引言→主题分节→展望）或研究论文（引言→方法→结果→讨论→结论）
- 每节带**目标字数 + 引用提示**（挂接白名单文献）

### 4. 写作（write）——逐章生成
- 按大纲分节生成（避免一次生成太长失真），每节独立落库
- **引用白名单强制**：prompt 明确只允许引用 search 步核验文献，引用即标 [n]
- 支持**断点续写**：未完成章节可继续生成

### 5. 质量巡检（quality）——自研三维检查
- **引用核验**：正文 [n] 引用是否都在白名单内、有无悬空引用
- **结构检查**：引言/方法/结果/结论等关键段落是否完整、长度是否达标
- **AI 味启发式**：连接词频率 / 句式重复 / "首先其次最后"模式 / 空话检测
- 输出问题清单（带位置提示），可一键跳到对应段落

### 6. 审稿（review）——多维评分
- Agent 以审稿人视角：新颖性 / 方法严谨性 / 数据呈现 / 语言表达 四维评分 + 具体修改建议
- 建议可逐条"应用到正文"（勾选式修改）

### 7. 导出（export）
- Markdown（默认，轻量可靠）
- LaTeX（复用老项目 _draft_to_latex 思路，GB/T 7714 参考文献块）
- Word 二期（python-docx）

## 四、生态联动（老项目没有的闭环）

1. **会话 ↔ 论文**：对话中选中的知识库 → 论文检索步自动用激活库
2. **论文 → 知识库回流**：导出后的论文可一键加入知识库（供后续对话检索）
3. **记忆沉淀**：写作偏好（引用格式/语气）自动进 Mem0，下次对话生效
4. **审批集成**：写作/检索调工具走 M5 审批策略（已有）

## 五、前端（主推功能体验）

- 论文工坊页重做：左侧项目列表 + 顶部 7 步步骤条 + 主区**大纲导航分栏** + 正文编辑区
- 每步产物可编辑 + 重新生成（重跑按钮）
- 生成过程 **SSE 流式**（思考/工具/文本实时可见，复用 M0 事件流）
- 引用角标 hover 浮层（复用现有 cite-pop 样式）
- 巡检/审稿结果以**问题清单 + 一键定位**呈现

## 六、实施阶段

| 阶段 | 内容 | 交付 |
|---|---|---|
| P1 | papers.db + 项目 CRUD + 状态机骨架 | 建项目/列表/步骤流转可用 |
| P2 | 选题/大纲/写作 三步（agent 流式生成 + 落库） | 核心写作链路 |
| P3 | 检索双通道 + 引用白名单 | 防幻觉引用 |
| P4 | 质量巡检 + 审稿 | 检查/评分闭环 |
| P5 | 导出 Markdown/LaTeX + 前端全部联动 | 全流程可用 |

## 七、相比老项目的优化点清单

1. ✅ 检索双通道（RAG + OpenAlex）——老项目仅 OpenAlex
2. ✅ SSE 流式生成（实时可见）——老项目异步轮询
3. ✅ 引用白名单落实到代码（写作 prompt 强制 + 巡检校验）
4. ✅ 质量巡检自研三维（不搬老项目 quality 模块）
5. ✅ 论文 ↔ 知识库 ↔ 记忆 生态闭环
6. ✅ 断点续写 + 失败重跑（继承老项目原则）
7. ✅ 审稿建议可勾选应用（老项目只输出意见）
8. ✅ 深度复用 matlens：事件流钩子/审批/记忆/知识库全部打通
