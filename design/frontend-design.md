# MatLens Agent 工作台 · 前端设计要求

> 版本 v0.1 · 2026-08-23 · 状态：评审中（先出设计，再实现）
> 关联：`design/brand-guide.md`（品牌规范）、`design/dev-plan.md`（开发计划）

---

## 1. 项目定位

MatLens Agent 工作台是面向**材料科研人员**的 Agent 工具。它不是一个聊天框，而是一个"科研 Agent 工作台"——用户在这里让 Agent 查性质、设计实验、处理数据、写论文，并**全程可见、可控、可审**（Codex 式事件流）。

**核心体验一句话**：像 Codex 一样干活，像科研助手一样懂材料。

---

## 2. 技术约束（必须遵守）

| 约束 | 要求 |
|---|---|
| 零构建链 | 原生 JS（ESM 模块化），无打包器/无框架，浏览器直接打开 |
| 单页应用 | 一个 index.html + modules/ 目录组织，左侧导航切换"页面" |
| 后端通信 | SSE 事件流（对话/任务）+ REST JSON（CRUD/审批回传） |
| 图表 | vis-network（CDN 引入）画记忆蜘蛛网 |
| 依赖 | 仅 CDN 引入（vis-network 等），其余纯原生 |
| 兼容 | 现代浏览器（Chrome/Edge/最新 Firefox），Windows 优先 |

---

## 3. 设计原则（品牌一致，延续 brand-guide.md）

1. **科研专业感**：深色主题为主，深蓝紫系，克制不花哨
2. **全程可见**：Agent 每一步（思考/工具/结果）都可展开查看——透明是第一原则
3. **可控可审**：危险操作必弹审批，用户始终掌握决策权
4. **信息分层**：主任务（对话流）在最显眼位置，辅助信息（记忆/引用/时间线）在侧栏，不抢占注意力

---

## 4. 信息架构（左侧导航，7 项）

```
💬 对话         事件流主界面（三栏）
📚 知识库       文献库管理 + 上传 + 检索配置
🧰 工具中心     全部工具（通用 32 + 材料 12）分类 + 参数表单
🧫 实验         实验方案向导 + 记录模板
📄 论文工坊     7 步论文工作流（选题→检索→大纲→写作→质量→审稿→导出）
🧠 记忆图谱     蜘蛛网记忆可视化 + 记忆管理
⚙️ 设置         模型 / 记忆 / 知识库 / 界面 / 安全
```

导航要求：图标 + 文字；当前项高亮（左侧 3px 蓝条）；小屏可收起为纯图标。

## 5. 布局规范

### 5.1 三栏骨架（对话页）

```
┌────────┬───────────────────────────────┬──────────────┐
│ 左侧栏  │        中间主区               │  右侧面板     │
│ 264px  │        flex:1                 │  320px       │
│        │                               │  可折叠       │
│ 导航    │   ▤ 会话标题 + 模型/知识库tag  │  📚 上下文    │
│ ─────  │  ───────────────────────────  │  - 记忆片段  │
│ 会话列表 │  事件流（滚动区）             │  - 引用文献  │
│ +新建   │  思考▾ / 🔧工具卡 / 审批卡     │  - 文件      │
│ 归档    │  回答（流式+引用角标）         │  🧬 工具时间线│
│        │  ───────────────────────────  │              │
│        │  输入区（多行/上传/发送/停止）  │              │
└────────┴───────────────────────────────┴──────────────┘
```

- 宽度：左侧 264px、右侧 320px，均**可拖拽调宽**（右侧可折叠）
- 小屏（<1024px）：右侧面板收为浮层（汉堡按钮唤起）

### 5.2 其他页面

- 非对话页：左侧导航 + 主内容区（无右侧面板），内容区自适应
- 论文工坊：主内容区纵向分步条（7 步 StepBar）+ 当前步骤面板

## 6. 核心组件规范

### 6.1 事件流组件（对话页核心，必须实现）

| 组件 | 视觉与交互 |
|---|---|
| **用户消息** | 右对齐气泡，深蓝底，浅色文字 |
| **思考卡** | 左对齐，灰色斜体，默认折叠为一行"💭 思考中…/思考过程"，点击展开 |
| **工具卡** | 边框卡片：`🔧 工具名(args)` + 状态徽标（运行中🟡转圈 / 成功🟢 / 失败🔴 / 审批中🟠）；点击展开参数与结果 |
| **审批卡** | 高亮边框（橙）+ 风险提示 + 工具名/参数摘要 + [批准] [拒绝] [记住此选择] 按钮 |
| **引用角标** | 回答中 `[1]` 上标，悬停浮层显示文献标题+命中片段+相似度，点击跳知识库 |
| **流式文本** | Markdown 渲染（代码高亮/表格/公式），增量追加，平滑滚动 |
| **错误卡** | 红色边框 + 友好错误说明 + 排查建议（不抛堆栈） |

### 6.2 会话列表（左侧栏）

- 会话项：标题 + 时间 + 工具数徽标；hover 显示 [重命名][归档][删除]
- 选中态高亮；"+" 新建；支持分支（fork）入口
- 会话自动标题（Agent 摘要生成）

### 6.3 上下文面板（右侧）

- 标签页：📚 记忆 / 📄 引用 / 📎 文件 / 🧬 时间线
- 记忆：本次召回的记忆片段列表（带类别标签 [用户]/[实验]/[材料]/[结论]）
- 时间线：本次任务所有工具调用的时间轴（名称+耗时+状态）

### 6.4 记忆图谱（蜘蛛网页）

- 力导向图（vis-network）：中心节点 = 用户/项目，发散材料/方法/性质/参数节点
- 节点按类型着色（材料🟦 方法🟩 性质🟪 参数🟨 人🟧），**关联越多节点越大**
- 点击节点 → 侧栏显示关联记忆条目（可编辑/删除）
- 顶部：记忆类别筛选 + 搜索框 + [重建图谱]

### 6.5 工具中心

- 分类分组（通用/材料计算/实验/数据/写作/浏览器）
- 工具卡：名称 + 简介 + [打开]；打开后右侧滑出参数表单（JSON Schema 渲染），执行结果原地展示

### 6.6 论文工坊

- 顶部 7 步 StepBar（选题→检索→大纲→写作→质量→审稿→导出），当前步高亮，可点击回退
- 每步独立面板；写作为主编辑器（Markdown 编辑+预览双栏）；导出选格式（Word/LaTeX/Markdown）
- 阶段状态徽标（未开始/进行中/完成/需返工）

## 7. 交互规范

1. **流式**：SSE 推送 token 级增量；底部自动跟随滚动，用户上滚暂停，滚到底恢复
2. **停止**：生成中显示 [■ 停止]；点击中断（SSE abort + 后端 cancel）
3. **审批**：审批卡出现时输入区锁定，批准/拒绝后恢复；"记住选择"写入策略
4. **悬停**：所有可展开组件 hover 高亮 + 轻微上浮（transition 0.15s）
5. **键盘**：Enter 发送 / Shift+Enter 换行 / Ctrl+L 清空 / Esc 关闭浮层
6. **加载**：按钮/提交有 loading 态动画；SSE 断线自动重连提示
7. **错误**：所有请求失败统一红色 toast，8s 可点击关闭，不显示原始堆栈

| 项 | 值 |
|---|---|
| 主色 | `#165DFF`（按钮/强调/选中） |
| 高亮 | `#00D4FF`（信息/链接） |

## 9. SSE 事件流协议（UI 对应）

| 事件 | 前端行为 |
|---|---|
| `thinking` | 渲染可折叠思考卡 |
| `tool_call` | 追加工具卡（运行中态） |
| `tool_result` | 更新工具卡（成功/失败）+ 时间线 |
| `approval_request` | 弹审批卡 + 锁定输入区 |
| `stream_text` | 流式追加回答文本 |
| `done` | 结束本轮，解锁输入区 |
| `error` | 错误卡 + toast |

---

## 10. 响应式与可用性

- ≥1280px：三栏全开；1024-1280：右侧折叠为浮层；<1024：左侧导航收为图标
- 最小宽度 800px（低于提示拉伸）
- 深/浅色主题切换（浅色用同色系浅底深字，见 brand-guide light 色板）
- 所有交互元素可键盘操作；对比度满足 WCAG AA

---

## 11. 页面优先级（实现顺序）

1. 对话页（三栏事件流）—— 最核心，先做
2. 设置页 —— 简单，早做可用
3. 知识库页 —— 依赖对话引用
4. 工具中心 —— 独立，中等
5. 记忆图谱 —— 依赖图谱后端
6. 实验页 / 论文工坊 —— 最后，工作流复杂
