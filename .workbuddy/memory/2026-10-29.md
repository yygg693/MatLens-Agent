### ⚠️ 踩的五个坑（都是实测出来的）
1. **User-Agent 含中文 → UnicodeEncodeError**。HTTP 头必须 latin-1 可编码。
   一开始 UA 写「MatLens/0.1 (材料化学研究工具)」直接炸。
2. **Zenodo 上论文远多于数据集**：「solid oxide fuel cell」命中 49 万，
   前 5 条全是 journal article。必须用**服务端** `type=dataset` 参数过滤，
   客户端滤会漏 subtype 变体还白跑一趟。
3. **`type=dataset` 里仍混着无文件的论文补充材料记录**：DOI 是出版商的
   （10.1002/xxx）、`files=[]`。判据应是**有无实际文件**，不是 type 字段 ——
   否则挤占检索结果且用户根本拿不到数据。
4. **空查询会让 Zenodo 返回「最近上传的任意数据集」**（ok=True 但内容与
   关键词无关）→ 直接拒绝。
5. **HTML 实体要用 html.unescape**：描述里常见 `&aring;` 这类命名实体，
   漏解会让 `&xxx;` 字面量进 prompt。

## 源健康自检与面板（`f8863ea`，+23 测试）

### 解决什么
此前只能「**用的时候才知道**」某个源挂了 —— 用户勾 5 个源去搜，结果少了一半
却不知道为什么少。自检让状态主动可见。

### 五档状态
`ok` / `degraded`（连通但探测词无命中）/ `down` / `need_key` / `off`

**need_key 与 down 必须分开**：没配密钥不是源坏了，是用户还没配置。
混为一谈会让用户以为源方挂了。

**失败原因分类**：配额耗尽 / 超时 / DNS / TLS / robots / 需密钥 ——
各类处置方式不同，只说「不可用」等于没说。

### 实测结果（这正是用户此前无法自己发现的）
- **DBLP**：反爬验证拦截
- **Semantic Scholar**：429 限流（隔一会儿又恢复 → 状态确实动态）
- **万方 / AMiner**：未配置密钥
- OpenAlex / Crossref / arXiv / Europe PMC / PubMed / Zenodo：正常

### ⚠️ 性能踩坑：27 秒 → 10.4 秒
三个原因叠加：
1. 并发数 6 → 10
2. **免重试模式**：`_http_get` 的 `retries=1` 会把 5s 超时翻倍成 10.8s。
   给 `scholarly` / `datasets` 加了 `_set_probe_mode()`，自检期间关掉重试
   （真实检索仍应重试 —— 那时多花几秒换来结果更值）。
3. **默认关闭的源不探测**：HuggingFace 的失败是 **DNS 解析超时**
   （WinError 10060，socket timeout 管不了），挂 10.9s 会把整体从 7s 拖到 17s。

### 缓存必须有
10 分钟 TTL。自检是网络操作，每次开页面都探会拖慢首屏、白耗免费 API 配额。
用户点「立即检测」才 force 刷新。

## 检索页接入「找 OA 全文」（`7f41237`，+23 测试）

检索步此前只产出**题录**，写作时需要的是**正文** —— 只有题录则 LLM 只能编。

### 前端
论文工坊检索步新增文献卡片区（16 条白名单逐条展示）：
- 每条显示 DOI + 「找 OA 全文」按钮（无 DOI 的标灰说明）
- 点一下 → Unpaywall 解析 → 抓正文 → 索引进知识库 → 标记「已抓到正文 N 字」
- 抓到后按钮变「重新抓取」，正文回写 refs 并持久化
- 失败**如实**显示原因（付费墙 / robots / 需手动下载）

后端 `POST /api/web/resolve-oa`（`{doi, title, authors, year, fetch?, kb?}`）。

### ⚠️ 踩的四个坑（全是实测撞出来的）
1. **UNPAYWALL_EMAIL 只读环境变量** —— 服务进程通常没有它（用户写在
   `~/.matlens/.env` 里），端点恒 502。补 `.env` 回落 + 可操作的报错提示，
   并已在用户 `.env` 写入配置（用 SMTP 那个 QQ 邮箱，同一联系地址最省事）。
2. **Unpaywall 的 `best_oa_location` 不能只用** —— 实测 best 常指向出版商
   域名（robots 禁止抓），同记录里还有 repository 镜像可抓。
   改为返回**全部候选**并按 repository 优先排序，逐个尝试。
3. **robots 不绕过** —— NCBI 的 `User-agent:*` 段明确 `Disallow: /pmc/articles/`，
   MDPI 同理。**robots 是站点的明确声明，换镜像硬抓即违规**。
   正确解法：转向**正规 API** —— 新增 `fetch_europepmc_fulltext()`
   （Europe PMC / EBI，按 DOI 取全文 XML，合法可编程访问）。
4. **字段被覆盖** —— Europe PMC 兜底设的 `engine`/`resolved_via` 被后续
   赋值覆盖成空，改用 `setdefault`。

  → **Europe PMC API 兜住 → 17941 字**入库
